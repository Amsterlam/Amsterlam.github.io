**Supervisor:** Lihua Cai

- Engineered an automated pipeline using computer vision and machine learning to predict drug efficacy from microscopy images, creating a scalable and non-destructive alternative to manual lab assays.
- Fine-tuned a YOLOv8n-seg model for instance segmentation to identify and classify organoid morphologies (e.g., hollow, solid), achieving 89% sensitivity on key structures.
- Trained a LightGBM model using 11 key morphological features to predict cell viability, achieving a mean R² of 0.633.
- Authored and visualized the complete methodology for a research manuscript, designing publication-quality diagrams for interdisciplinary audiences.
