- Engineered an end-to-end forward collision warning system, from schematic design and hardware implementation to firmware development on an 8-bit MCU.
- Implemented a sensor fusion algorithm combining ultrasonic and infrared sensors, enhancing detection accuracy and minimizing false positives.
- Programmed multi-stage warning logic with tiered distance thresholds, triggering escalating audible and visual alerts.
- Established a wireless UART link to broadcast real-time distance data to a remote monitoring unit.
