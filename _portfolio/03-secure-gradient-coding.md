**Supervisor:** Jun Li

- Architected a Byzantine-resilient and straggler-tolerant distributed training framework by integrating Fractional Repetition Code (FRC) with a custom decoding algorithm.
- Designed and implemented the robust decoding algorithm, leveraging linear independence of gradient subsets created by the FRC scheme.
- Enabled the system to mathematically identify and correct malicious errors from Byzantine attackers, ensuring recovery of the correct full gradients and protecting data integrity.
